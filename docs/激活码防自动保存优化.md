# 激活码输入框防自动保存优化

## 已实现的优化

### 1. HTML属性防护
- `autoComplete="new-password"` - 防止浏览器自动填充
- `data-lpignore="true"` - 防止密码管理器记录
- 随机name属性 - 防止浏览器记忆表单

### 2. JavaScript清理
- 页面加载时清空所有输入框
- 清除localStorage/sessionStorage相关数据
- 页面卸载时自动清理

### 3. 保持的功能
- 8个输入框布局不变 (ID: activation-code-0 到 activation-code-7)
- 占位符显示 (A,B,C,1,2,D,3,4)
- 自动聚焦和键盘导航
- 粘贴功能支持

## 效果
✅ 页面刷新后输入框为空
✅ 浏览器不显示自动填充建议  
✅ 密码管理器不记录激活码
✅ 不影响其他表单字段的自动填充
