# 增强日志系统使用指南

## 概述

本日志系统为Tauri应用提供了完整的结构化日志记录功能，支持实时日志监控、文件持久化、多级别日志分类等功能。

## 核心特性

- **结构化日志**: 所有日志包含时间戳、来源、上下文等完整信息
- **实时持久化**: 日志同时保存到内存和文件系统
- **多级别分类**: 支持info、warning、error、debug等日志级别
- **用户操作追踪**: 专门记录用户交互行为
- **设备事件记录**: 设备连接、断开等事件追踪
- **性能监控**: 操作耗时监控和性能分析
- **错误边界**: React错误边界自动捕获和记录

## 快速开始

### 1. 基本导入

在任何React组件或TypeScript文件中导入日志服务：

```typescript
import enhancedLogService from '../services/enhancedLogService';
```

### 2. 基础日志记录

#### 信息日志
```typescript
enhancedLogService.logInfo("操作成功", "组件名", { detail: "具体信息" });
```

#### 警告日志
```typescript
enhancedLogService.logWarning("磁盘空间不足", "StorageManager", { freeSpace: "1.2GB" });
```

#### 错误日志
```typescript
try {
  // 业务代码
} catch (error) {
  enhancedLogService.logError("操作失败", "组件名", { 
    error: error instanceof Error ? error.message : String(error)
  }, "ERROR_CODE");
}
```

#### 调试日志
```typescript
enhancedLogService.logDebug("组件渲染完成", "UserProfile", { userId: 123 });
```

## React组件集成示例

### 功能组件示例

```typescript
import React from 'react';
import enhancedLogService from '../services/enhancedLogService';

const UserManagementComponent: React.FC = () => {
  // 组件挂载时记录
  React.useEffect(() => {
    enhancedLogService.logInfo("组件已挂载", "UserManagementComponent");
    
    return () => {
      enhancedLogService.logInfo("组件已卸载", "UserManagementComponent");
    };
  }, []);
  
  const handleUserLogin = (username: string) => {
    try {
      // 记录用户登录操作
      enhancedLogService.logUserAction("user_login", "UserManagement", { 
        username,
        timestamp: new Date().toISOString()
      });
      
      // 业务逻辑...
      enhancedLogService.logInfo("用户登录成功", "UserManagement", { username });
      
    } catch (error) {
      enhancedLogService.logError("用户登录失败", "UserManagement", { 
        username,
        error: error instanceof Error ? error.message : String(error)
      }, "LOGIN_ERROR");
    }
  };

  return (
    <div>
      <button onClick={() => handleUserLogin("testuser")}>登录</button>
    </div>
  );
};
```

### 错误边界组件

```typescript
import React from 'react';
import enhancedLogService from '../services/enhancedLogService';

class ErrorBoundary extends React.Component {
  componentDidCatch(error: Error, errorInfo: React.ErrorInfo) {
    enhancedLogService.logErrorBoundary(error, "ErrorBoundary", "React", {
      componentStack: errorInfo.componentStack
    });
  }

  render() {
    return this.props.children;
  }
}
```

## 服务类集成示例

### API服务示例

```typescript
import enhancedLogService from '../services/enhancedLogService';

export class ApiService {
  async fetchData(url: string) {
    try {
      enhancedLogService.logInfo("开始API请求", "ApiService", { url });
      
      const response = await fetch(url);
      
      enhancedLogService.logInfo("API请求成功", "ApiService", { 
        url, 
        status: response.status 
      });
      
      return await response.json();
      
    } catch (error) {
      enhancedLogService.logError("API请求失败", "ApiService", { 
        url,
        error: error instanceof Error ? error.message : String(error)
      }, "API_ERROR");
      
      throw error;
    }
  }
}
```

## 日志文件管理

### 文件格式

日志文件格式：`admt_log_YYYY-MM-DD.log`

### 文件位置

- **开发环境**: 项目根目录下的 `logs` 文件夹
- **生产环境**: 应用数据目录下的 `logs` 文件夹

### 保留策略

- **普通日志**: 保留30天
- **错误日志**: 保留180天
- **内存日志**: 最多保留2000条

## 最佳实践

### 1. 适当的日志级别

- **info**: 一般操作记录
- **warning**: 需要注意但非错误的情况
- **error**: 错误和异常情况
- **debug**: 调试信息（开发环境使用）

### 2. 详细的上下文信息

```typescript
// 好的实践
enhancedLogService.logInfo("文件上传成功", "FileUploader", {
  fileName: "document.pdf",
  fileSize: "2.5MB",
  uploadTime: "1500ms",
  userId: "user123"
});

// 避免的实践
enhancedLogService.logInfo("操作成功", "组件");
```

### 3. 错误处理

```typescript
try {
  // 业务代码
} catch (error) {
  enhancedLogService.logError("操作失败", "ServiceName", {
    errorName: error.name,
    errorMessage: error.message,
    stackTrace: error.stack,
    operationContext: "具体的操作上下文"
  }, "SPECIFIC_ERROR_CODE");
}
```

### 4. 性能监控

```typescript
const startTime = Date.now();

// 执行操作
await performExpensiveOperation();

const duration = Date.now() - startTime;
if (duration > 1000) {
  enhancedLogService.logWarning("操作耗时较长", "PerformanceMonitor", {
    operation: "expensiveOperation",
    duration: `${duration}ms`,
    threshold: "1000ms"
  });
}
```

## 故障排除

### 常见问题

1. **日志不显示**: 检查日志服务是否已初始化
2. **文件写入失败**: 检查文件权限和磁盘空间
3. **内存占用过高**: 检查内存日志保留数量设置

### 调试模式

启用调试模式查看详细日志信息：

```typescript
// 设置日志级别为debug
enhancedLogService.logDebug("调试信息", "DebugComponent", { debugData });
```
