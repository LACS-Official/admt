# 弹窗通知使用指南

## 概述

本应用中的弹窗通知系统通过状态栏组件实现，支持多种类型的通知消息，并提供自动消失和手动关闭功能。

## 通知类型

通知系统支持以下四种类型的通知：

1. **成功通知 (success)** - 绿色背景，用于表示操作成功
2. **错误通知 (error)** - 红色背景，用于表示错误信息
3. **警告通知 (warning)** - 黄色背景，用于表示警告信息
4. **信息通知 (info)** - 蓝色背景，用于表示一般信息

## 通知显示特性

- **自动消失**：通知默认显示3秒后自动消失
- **进度条**：通知底部显示进度条，直观展示剩余显示时间
- **手动关闭**：用户可点击关闭按钮立即关闭通知
- **优先级**：状态栏消息优先级高于通知消息
- **动画效果**：通知显示和隐藏带有平滑的过渡动画

## 使用方法

### 1. 添加通知

通过应用状态管理器添加通知：

```typescript
import { useAppStore } from '../stores/appStore';

const { addNotification } = useAppStore();

// 添加成功通知
addNotification({
  type: 'success',
  title: '操作成功',
  message: '文件已成功保存'
});

// 添加错误通知
addNotification({
  type: 'error',
  title: '操作失败',
  message: '网络连接错误，请重试'
});

// 添加警告通知
addNotification({
  type: 'warning',
  title: '注意',
  message: '磁盘空间不足'
});

// 添加信息通知
addNotification({
  type: 'info',
  title: '提示',
  message: '新版本已发布'
});
```

### 2. 状态栏消息

对于需要更高优先级的消息，可以使用状态栏消息：

```typescript
import { useAppStore } from '../stores/appStore';

const { setStatusBarMessage } = useAppStore();

// 设置状态栏消息
setStatusBarMessage({
  type: 'warning',
  message: '正在执行重要操作，请勿关闭应用'
});

// 清除状态栏消息
clearStatusBarMessage();
```

## 通知数据结构

### NotificationMessage

```typescript
interface NotificationMessage {
  id: string;        // 通知唯一标识符
  type: 'success' | 'error' | 'warning' | 'info';  // 通知类型
  title: string;     // 通知标题
  message: string;   // 通知内容
  timestamp?: number; // 时间戳（可选）
}
```

### StatusBarMessage

```typescript
interface StatusBarMessage {
  type: 'success' | 'error' | 'warning' | 'info';  // 消息类型
  message: string;   // 消息内容
  icon?: React.ReactNode;  // 自定义图标（可选）
}
```

## 最佳实践

1. **合理使用通知类型**：根据消息性质选择合适的通知类型，避免过度使用错误通知

2. **简洁明了的消息**：通知消息应简短明了，突出重点信息

3. **避免频繁通知**：短时间内避免发送过多通知，以免影响用户体验

4. **优先级考虑**：对于关键系统消息，使用状态栏消息而非普通通知

5. **国际化支持**：通知内容应支持多语言，使用应用的语言配置

## 注意事项

1. 通知会按队列顺序显示，同时只显示一个通知
2. 状态栏消息会覆盖当前显示的通知
3. 通知组件会自动管理清理，无需手动移除
4. 在应用卸载时，所有定时器会被自动清理

## 样式自定义

通知样式可通过修改 `StatusBar.tsx` 中的样式类进行自定义：

- `notificationSuccess` - 成功通知样式
- `notificationError` - 错误通知样式
- `notificationWarning` - 警告通知样式
- `notificationInfo` - 信息通知样式

## 示例代码

完整的使用示例：

```typescript
import React from 'react';
import { Button } from '@fluentui/react-components';
import { useAppStore } from '../stores/appStore';

const NotificationExample: React.FC = () => {
  const { addNotification } = useAppStore();

  const showSuccessNotification = () => {
    addNotification({
      type: 'success',
      title: '保存成功',
      message: '您的设置已成功保存'
    });
  };

  const showErrorNotification = () => {
    addNotification({
      type: 'error',
      title: '连接失败',
      message: '无法连接到服务器，请检查网络设置'
    });
  };

  const showWarningNotification = () => {
    addNotification({
      type: 'warning',
      title: '磁盘空间不足',
      message: '剩余空间少于10%，请及时清理'
    });
  };

  const showInfoNotification = () => {
    addNotification({
      type: 'info',
      title: '更新提示',
      message: '发现新版本，建议立即更新'
    });
  };

  return (
    <div>
      <Button onClick={showSuccessNotification}>显示成功通知</Button>
      <Button onClick={showErrorNotification}>显示错误通知</Button>
      <Button onClick={showWarningNotification}>显示警告通知</Button>
      <Button onClick={showInfoNotification}>显示信息通知</Button>
    </div>
  );
};

export default NotificationExample;
```
