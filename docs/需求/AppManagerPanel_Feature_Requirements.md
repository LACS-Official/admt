# AppManagerPanel 进阶功能需求文档

## 1. 引言

本文档旨在记录并规划 `AppManagerPanel`（ADB 应用管理器界面）未来可以扩展和加入的进阶功能。当前面板已经实现了应用查看（包括系统应用、普通应用、冻结应用、前台应用）以及基础的应用管理（卸载、冻结/解冻、强制停止、清除数据、导出APK和应用列表导入导出）。为了进一步提升该工具的专业性和用户体验，计划加入以下功能。

---

## 2. 核心进阶功能规划

### 2.1 应用安装与部署扩展 (App Installation)

- **需求目的**：不仅能卸载和导出，还要增强用户为设备快速安装应用的能力。
- **具体功能点**：
  - **拖拽安装 / 批量安装**：支持用户直接将 `.apk` 或 `.apks` / `.xapk` / `.zip` 安装包拖入面板区域进行自动安装。
  - **高级安装选项设定**：在主界面或设置面板中支持安装选项的勾选配置，并在安装时附加这些参数：
    - 允许降级安装 (`-d`)
    - 覆盖安装 (`-r`)
    - 测试应用安装 (`-t`)
    - 指定安装存储位置（如内部/外部存储）。

### 2.2 便捷的应用单体交互 (App Interaction)

- **需求目的**：提升针对设备上单个应用的快捷操作和调试效率。
- **具体功能点**：
  - **直接启动应用 (Launch App)**：在应用操作菜单（或快捷按钮）中添加启动选项。PC 端触发后，通过命令 `monkey -p <pkg> -c android.intent.category.LAUNCHER 1` 直接在移动端拉起该应用。
  - **跳转系统应用详情页**：增加“在设备上打开应用详情”选项，方便用户手动检查通知或调整高级权限（通过 `am start -a android.settings.APPLICATION_DETAILS_SETTINGS -d package:<pkg>` 实现）。
  - **在应用市场中查看**：通过 Intent 唤起 Google Play 或其他设备默认应用商店，展示该应用的商店详情页。

### 2.3 应用数据与深度分析 (App Analytics & Info)

- **需求目的**：提供更丰富的应用元数据展示，帮助用户（尤其是开发者或性能测试人员）深入了解应用。
- **具体功能点**：
  - **应用存储空间分析**：分析并展示该应用的 **APK 大小**、**存储数据大小** 以及 **缓存占用大小**。
  - **高级排序机制**：在原有的名称过滤外，增加表格列的排序功能，例如“按安装时间”、“按更新时间”或“按应用体积大小”进行降序/升序排列，以便用户快速找出占空间的大型应用或最新安装的应用。
  - **深度的组件和 SDK 信息展示**：完善现有的“详情信息”对话框，展示其内部细节：
    - `Target SDK`
    - `Min SDK`
    - `ABI 架构 (32位/64位)`
    - 提供各项组件 (`Activities`, `Services`, `Receivers`, `Providers`) 的注册信息概览。
  - **应用权限分析与管控**：展示该应用申请的具体危险权限列表，并提供 PC 端的快速授权/撤销功能 (`pm grant / pm revoke`)。

### 2.4 数据级备份与恢复 (Backup & Restore)

- **需求目的**：方便进行应用存档或在多设备/刷机场景下进行数据迁移。
- **具体功能点**：
  - **应用数据打包备份**：针对支持备份（或在 Root 授权下）的应用，将其 `/data/data/<pkg>` 及相关扩展存储数据打包拉取到电脑。
  - **数据恢复与推流**：配合 APK 安装，将备份好的数据压缩包推送并恢复回设备相应位置。

### 2.5 系统级高级操作 (Root/高级授权向)

- **需求目的**：为拥有 Root 或 Magisk 环境的设备提供更底层的包管理方案。
- **具体功能点**：
  - **应用属性转换**：支持“用户应用转系统应用”及“系统应用转用户应用”。
  - **深度系统应用卸载**：提供真正的系统级彻底删除（清理 system 分区），而不仅限于 `pm uninstall -k --user 0` 的当前用户屏蔽卸载。
  - **遗留无用数据清理**：扫描并清理已卸载应用的残留目录与僵尸文件。

---

## 3. 开发优先级建议

针对上述规划，从**开发成本**与**用户体验提升(ROI)**角度评估，建议首选实现以下特性：

1. **[P0]** 拖拽/批量选择安装 APK 界面支持。
2. **[P0]** 单体应用菜单增加 "一键启动应用" 与 "打开系统详情页" 快捷键操作。
3. **[P1]** 列表支持高级排序功能（按 空间大小 / 安装时间 / 更新时间）。
4. **[P2]** 应用信息详情窗口增强（增加 SDK 及组件等开发者数据分析）。
