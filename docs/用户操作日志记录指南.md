# 用户操作日志记录指南

## 概述

本指南说明如何在应用的各个页面中记录用户操作日志，使这些操作能够在LogsPanel中显示。

## 基本使用方法

### 1. 导入日志服务

在需要记录用户操作的组件中，首先导入enhancedLogService：

```typescript
import { enhancedLogService } from '../../services/enhancedLogService';
```

### 2. 记录用户操作

在用户操作事件中调用`enhancedLogService.logUserAction()`方法：

```typescript
enhancedLogService.logUserAction(
  "操作描述", 
  "组件名称", 
  { 上下文信息 }
);
```

### 3. 参数说明

- **action** (string): 用户操作的描述，如"点击按钮"、"提交表单"等
- **source** (string): 操作来源的组件名称，如"LoginComponent"、"SettingsPage"等
- **context** (object, 可选): 相关的上下文信息，如按钮ID、表单数据等

## 常见使用场景

### 1. 按钮点击

```typescript
const handleButtonClick = () => {
  // 记录按钮点击
  enhancedLogService.logUserAction("点击登录按钮", "LoginComponent", {
    buttonId: "loginButton",
    timestamp: new Date().toISOString()
  });
  
  // 执行登录逻辑...
};
```

### 2. 表单提交

```typescript
const handleFormSubmit = (event: React.FormEvent) => {
  event.preventDefault();
  
  const formData = new FormData(event.target as HTMLFormElement);
  const data = Object.fromEntries(formData.entries());
  
  // 记录表单提交（注意：过滤敏感数据）
  const { password, ...safeData } = data;
  enhancedLogService.logUserAction("提交登录表单", "LoginComponent", {
    formId: "loginForm",
    formData: safeData,
    timestamp: new Date().toISOString()
  });
  
  // 执行表单提交逻辑...
};
```

### 3. 设置更改

```typescript
const handleSettingChange = (settingName: string, value: any) => {
  // 获取旧值
  const oldValue = getCurrentSettingValue(settingName);
  
  // 记录设置更改
  enhancedLogService.logUserAction(`更改设置: ${settingName}`, "SettingsComponent", {
    settingName,
    oldValue,
    newValue: value,
    timestamp: new Date().toISOString()
  });
  
  // 执行设置更改逻辑...
};
```

### 4. 页面访问

```typescript
React.useEffect(() => {
  // 记录页面访问
  enhancedLogService.logUserAction("访问设置页面", "SettingsPage", {
    pageUrl: window.location.pathname,
    timestamp: new Date().toISOString()
  });
}, []);
```

### 5. 设备操作

```typescript
const handleDeviceConnect = () => {
  // 记录设备连接操作
  enhancedLogService.logUserAction("连接设备", "DeviceManager", {
    deviceId: selectedDevice.id,
    deviceModel: selectedDevice.model,
    timestamp: new Date().toISOString()
  });
  
  // 执行设备连接逻辑...
};
```

## 最佳实践

### 1. 提供有意义的操作描述

```typescript
// 好的示例
enhancedLogService.logUserAction("开始固件刷写", "FirmwareFlasher", {...});

// 不好的示例
enhancedLogService.logUserAction("点击", "Component", {...});
```

### 2. 提供足够的上下文信息

```typescript
// 好的示例
enhancedLogService.logUserAction("更改主题设置", "SettingsComponent", {
  settingName: "theme",
  oldValue: "light",
  newValue: "dark",
  timestamp: new Date().toISOString()
});

// 不好的示例
enhancedLogService.logUserAction("更改设置", "SettingsComponent", {});
```

### 3. 避免记录敏感数据

```typescript
// 好的示例 - 过滤敏感数据
const { password, token, ...safeData } = formData;
enhancedLogService.logUserAction("提交用户表单", "UserForm", {
  formData: safeData
});

// 不好的示例 - 记录敏感数据
enhancedLogService.logUserAction("提交用户表单", "UserForm", {
  formData: formData // 包含密码等敏感信息
});
```

### 4. 在关键操作点记录日志

```typescript
// 在组件挂载时记录页面访问
React.useEffect(() => {
  enhancedLogService.logUserAction("访问用户管理页面", "UserManagement", {
    pageUrl: "/users"
  });
}, []);

// 在重要操作前记录
const handleDeleteUser = () => {
  enhancedLogService.logUserAction("删除用户", "UserManagement", {
    userId: user.id,
    userName: user.name
  });
  
  // 执行删除操作...
};
```

## 日志查看

记录的用户操作日志会自动显示在LogsPanel中，可以通过以下方式查看：

1. 导航到设置页面
2. 点击"日志"选项卡
3. 在日志列表中查看用户操作记录
4. 可以使用过滤器按级别、分类、设备等筛选日志

## 示例组件

参考`ExampleComponent.tsx`组件，它包含了各种用户操作日志记录的示例实现。

## 注意事项

1. **性能考虑**: 避免在高频事件中记录日志，如鼠标移动、窗口调整等
2. **数据安全**: 不要记录敏感信息，如密码、令牌、个人身份信息等
3. **日志大小**: 合理设置日志保留策略，避免日志文件过大
4. **错误处理**: 日志记录失败不应影响主要功能的正常运行

通过遵循以上指南，您可以在应用的各个页面中有效地记录用户操作，并在LogsPanel中集中查看这些操作日志。
