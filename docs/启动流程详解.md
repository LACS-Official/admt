# ADMT应用启动流程详解

## 概述

ADMT (Android Device Management Tool) 是一个基于 Tauri + React 的桌面应用程序。本文档详细描述了从应用启动到主页面显示的完整流程，包括每个组件的调用关系和方法实现。

## 启动流程架构图

```
main.tsx
    ↓
AppWithTheme (主题管理)
    ↓
App.tsx (应用主入口)
    ↓
StartupFlowManager (启动流程管理器)
    ↓
UnifiedLoadingVersionChecker (版本检查和加载)
    ↓
StartupVersionChecker (版本检查弹窗)
    ↓
PrivacyConsentDialog (隐私政策对话框)
    ↓
ActivationPage (激活验证页面)
    ↓
MainContent (主应用界面)
```

function AppWithTheme() {
  const { isDarkMode, followSystemTheme, updateThemeBasedOnSystem } = useThemeStore();
  
  // 监听系统主题变化
  useEffect(() => {
    if (followSystemTheme) {
      updateThemeBasedOnSystem();
      const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
      const handler = () => updateThemeBasedOnSystem();
      mediaQuery.addEventListener('change', handler);
      return () => mediaQuery.removeEventListener('change', handler);
    }
  }, [followSystemTheme, updateThemeBasedOnSystem]);
}
```

#### 1.3 调用流程

const handleStartupFlowError = async (error: string) => {
  logService.error('启动流程失败', 'App', error);
  setError(error);
  setShowStartupFlow(false);
  setIsMainContentLoading(false);
  setShowErrorNotification(true);
  setCountdown(5);
  
  // 倒计时退出应用
  const countdownInterval = setInterval(() => {
    setCountdown(prev => {
      if (prev <= 1) {
        clearInterval(countdownInterval);
        setTimeout(async () => {
          try {
            const { exit } = await import('@tauri-apps/plugin-process');
            await exit(1);
          } catch (exitError) {
            window.close();
          }
        }, 100);
        return 0;
      }
      return prev - 1;
    });
  }, 1000);
};
```

const performChecks = async () => {
  try {
    // 初始化安全配置
    setProgress(85);
    setStatusMessage('初始化安全配置...');

    await configManager.initialize();

    // 获取当前版本

    // 并行执行版本检查和公告检查

      checkLatestVersion(currentVersion),

#### 4.3 版本检查方法 `checkLatestVersion()`

```typescript
const checkLatestVersion = async (currentVersion: string): Promise<VersionCheckResult> => {
  try {
    // 初始化安全数据传输服务
    const transmissionService = SecureDataTransmissionService.getInstance();
    await transmissionService.initialize();

    // 获取软件信息
    const configManager = SecurityConfigManager.getInstance();
    const softwareId = configManager.getSoftwareId();
    
    const softwareResponse = await transmissionService.sendSecureRequest(`/app/software/id/${softwareId}`);
    
    if (!softwareResponse.success || !softwareResponse.data) {
      throw new Error(softwareResponse.error || '获取软件信息失败');
    }

    const softwareInfo = softwareResponse.data;
    const latestVersionNumber = softwareInfo.currentVersion || currentVersion;
    const isLatest = compareVersions(currentVersion, latestVersionNumber) >= 0;

    return {
      isLatest,
      currentVersion,
      latestVersion: latestVersionNumber,
      updateInfo: !isLatest ? {
        version: latestVersionNumber,
        releaseDate: new Date().toISOString(),
        description: softwareInfo.description || '发现新版本，需要更新后才能继续使用',
        downloadUrl: softwareInfo.latestDownloadUrl || softwareInfo.officialWebsite || '',
        isForced: true,
        title: `新版本 ${latestVersionNumber} 可用`,
      } : undefined,
    };
  } catch (error) {
    throw new Error(`版本检查失败: ${error instanceof Error ? error.message : '未知错误'}`);
  }
};
```

const performVersionCheck = useCallback(async () => {
  try {
    setIsChecking(true);
    setError(null);
    
    const result = await versionService.checkForUpdates();
    setCheckResult(result);
    
    if (result.needsUpdate) {
      setShowDialog(true);
      showUpdateToast();
    } else {
      showSuccessToast();
      setTimeout(() => {
        onCheckComplete(false, result);
      }, 1500);
    }
  } catch (error) {
    const errorMessage = error instanceof Error ? error.message : '版本检查失败';
    setError(errorMessage);
    setShowDialog(true);
  } finally {
    setIsChecking(false);
  }
}, [onCheckComplete]);
