# 玩机管家 (ADMT) v1.5.3 更新日志

## 新增
- 投屏按键映射工作室（Beta）：自定义键位、连点、预设导入导出与双输入通道。
- 全局下载进度胶囊：实时显示百分比与速率，完成后自动收起。

## 优化
- 对齐极简设计规范：移除长篇警告与浮夸文案，高危操作确认框只列客观参数。
- 托盘右键菜单精简为「显示主页面 / 退出程序」，避免误触与抢焦。
- 打通捐赠墙外部浏览器跳转，修复 WebView 拦截导致的无响应。

## 修复
- 修复 AI 助手默认模型失效，改用用户自选模型并校准采样温度。
- 修复「跟随系统改变主题」失效，新增注册表/窗口 API/媒体查询三级探测。
