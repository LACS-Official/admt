# 玩机管家 (ADMT) v1.5.6 更新日志

## 新增
- 启动时检测 ADB / Fastboot 工具链，状态栏常驻环境指示器。
- 投屏按键映射打通后端事件注入，支持 `input motionevent` 与降级 `input tap`。
- Root 镜像修补支持 Magisk / KernelSU / SukiSU Ultra / APatch，含分区选择、KMI 检测、刷入确认与 AVB 可选关闭；一键 Root 入口暂隐藏。
- 标准日志出口与历史日志回看；日志保留时长默认一周，可调至四周或永久。

## 优化
- 修复系统托盘在 Tauri 2 下的判定与菜单重建。
- 首页刷新设备真正执行扫描；应用内统一确认框替代原生 `window.confirm`。
- 圆角改为主题变量，随显示设置三档实时生效。
- 统一配色令牌、清理装饰性动画与模板化文案；修复弹窗与窄窗口越界。
- 去冗余、依赖精简，新增 CI 与契约测试；补齐社区标准文档。

## 修复
- 修复 Root 工具下载失败：改用 Release API、代理与镜像多候选回退、文件校验与错误链解析。
- 修复下载取消残留、CSP 与权限收紧、Fastboot 命令卡片转义。
