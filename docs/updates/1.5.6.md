# 玩机管家 (ADMT) v1.5.6 更新日志

本次更新把重心放在 **工具链可靠性与工程可维护性**：补齐启动时的 ADB / Fastboot 环境检测、打通投屏按键映射、修正系统托盘在 Tauri 2 下的判定，并把 Root 镜像修补从单一 Magisk 扩展到 Magisk / KernelSU / SukiSU Ultra / APatch 四种引擎的 PC 原生修补与刷入闭环。同时建立全项目统一的标准日志规范，完成一轮代码库去冗余与依赖精简，并新增 CI 工作流与契约测试。界面侧完成首批视觉收敛：统一圆角令牌、移除水印与装饰性动画。

---

### 🚀 新增功能

#### 1. 启动时工具链检测
- 新增 `envCheckService` 与后端环境探测命令，启动时检查 ADB / Fastboot 是否可用；状态栏常驻一枚环境状态指示器，工具缺失时额外显示一条可关闭的提醒横幅，仅提供手动引导，不自动安装驱动；三语补齐 `env.*` 文案。

#### 2. 投屏按键映射
- 后端 `adb/scrcpy/key_mapping.rs` 读取 `wm size`、探测 `input motionevent` 支持（不支持时降级为 `input tap`），用独立 worker 处理按键事件并按 `ADMT - {serial}` 精确匹配投屏窗口；新增 `inject_key_mapping_event` 与 `get_key_mapping_diagnostics` 命令；前端把投屏面板的 keydown / keyup 桥接到设备触控。

#### 3. Root 镜像修补全链路
- **分区参数化**：Magisk 修补按 `{partition}.img` / `new-{partition}.img` 解包与重打包，修正 Android 13+ GKI 设备误用 boot 分区的问题；
- **多引擎**：KernelSU / SukiSU Ultra 通过 `ksud boot-patch --kmi --partition` 注入预编译内核模块，APatch 通过 `kptools unpack → -p --skey --kpimg → repack` 修补内核（强制 boot 分区）；工具由 `ensure_root_patch_tool` 自动下载；
- **闭环**：新增 `root_flash_patched_image`（可选 `--disable-verification vbmeta`）与 `root_detect_kmi`，前端修补面板提供引擎/分区选择、KMI 检测、SuperKey、产物路径与刷入二次确认；
- 一键 Root 入口按产品决策暂时隐藏，待真机验证全链路后再开放。

#### 4. 标准日志与历史回看
- `AGENTS.md` 新增第 6 节统一出口（后端 `log::*` / 前端 `logService`）、四类打点要求与失败日志格式约束；默认采集级别统一为 `error / warning / info`；
- 后端新增 `read_plugin_log_files` 读取 LogDir，日志页新增「载入历史」「打开日志目录」，会话实时流与磁盘日志可同时查看。

### ⚡ 体验优化

#### 1. 系统托盘可用
- 修正前端误用 Tauri 1 的 `window.__TAURI__` 判定，改为 `isTauri()` + `is_system_tray_supported`；后端用 `remove_tray_by_id` 重建菜单并接入自定义菜单项，图标缺失时返回明确错误而非静默失败。

#### 2. 界面视觉首批收敛
- 全局圆角令牌由 2/4/8px 调整为卡片 12–16px、交互控件 9999px 胶囊；移除全局平铺水印、根容器渐变背景、无限脉冲与扫光动画，启动转场简化为短淡入；多行文本域按卡片圆角处理。

#### 3. 代码库去冗余
- 删除 33 个确证零引用文件；`deviceService` 直接复用唯一 `logService`，`get_file_hash` 复用 `root::patch::sha256_file`，四份同构配置加载收敛为 `readConfigWithFallback`；
- 清理 189 个未使用绑定、13 个 Rust 死函数、9 个 TODO 假实现；Cargo 移除 `regex / futures / time / anyhow`，npm 移除 6 个零引用包与 2 个重复 lint 包，同步锁文件；
- `AGENTS.md` 新增第 7 节「复用优先与反冗余规范」，固化先检索后编写、唯一实现入口、新增依赖门槛与改动后四项验证。

### 🛠️ 问题修复

#### 1. Root 工具下载失败
- 根因是把 GitHub **网页地址**当 release API 请求（返回 HTML 解析崩溃），且 `reqwest` 未读取本机代理，匿名 API 触发 403 限流；
- 改为 `api.github.com/repos/.../releases/latest` + 直连 / `gh-proxy.com` / `ghproxy.net` 多候选回退，代理来源补充环境变量与 Windows 注册表，下载结果增加 0 字节 / 小文件校验后切换候选；前端用 `extractErrorMessage` 解析真实错误链，不再出现 `[object Object]`。

#### 2. 下载与命令执行安全
- Fastboot 命令卡片改为分段 HTML 转义，CSP 移除 `unsafe-eval`，`capabilities` 删除宽泛 HTTP 权限；`cancel_download` 真正中断任务、删除残件并返回 `DOWNLOAD_CANCELLED`；在线资源监听改 Map 化管理。

#### 3. 测试与 CI
- 新建 Vitest 体系（setup / i18n / commandRegistry / security），契约测试覆盖 Root 命令注册、分区参数化、工具下载与标准日志链路，共 28 项；新增 `.github/workflows/ci.yml`。

### 🎨 界面与体验优化（第二批）

#### 1. 交互失效修复
- 首页「刷新设备」原来只显示提示文案、不执行扫描；现改为真正调用 `scanDevices` 并写回设备列表，带成功/失败反馈（三语补齐 `status.device_list_refreshed` 等）。
- 主内容区容器去掉 `height:100vh`，改弹性高度 + `minHeight:0`，修复叠加标题栏/状态栏后底部被静默裁切的问题。

#### 2. 应用内统一确认框
- 全部 6 处原生 `window.confirm`（刷入镜像、快捷命令分类删除、显示参数恢复、下载记录清理、管理员提权）改为应用内 Fluent Dialog，深色主题不再割裂，长路径可换行；
- 新增全局唯一确认服务 `confirmService`（Promise API，组件层与纯 TS service 层通用）与挂载于 App 根部的 `ConfirmDialogHost`，替代各模块各自实现。

#### 3. 设计规范对齐
- 高饱和 Bootstrap 色与品牌蓝统一映射为 Fluent 主题令牌（84 处），移除设备状态点的发光光晕与多处蓝色外发光、毛玻璃模糊；
- 清理快捷按钮与导出报告中的 Emoji，简化「下一代极致体验」等模板化说教文案（三语同步）；
- 移除状态栏重复的营销串，Star 图标改中性色。

#### 4. 窄窗口适配
- 五处面板胶囊导航改为 `maxWidth:100% + 横向滚动`，不再被裁切；
- 五个分栏布局固定像素列改 `minmax(0, Npx)`；四处弹窗加 `92vw/86vh` 上限并去除冲突的 `minHeight`；
- 日志页过滤行支持换行、长设备序列号省略显示、下拉菜单右对齐避免越界。

#### 5. 圆角联动显示设置
- 全库 590+ 处写死圆角改为 `--admt-radius-*` 变量，随「显示设置 → 圆角风格」三档（较小/适中/较大）即时生效；按钮与选项卡保持 9999px 胶囊。

#### 6. 日志保留时长
- 日志默认保留一周，可调一周/两周/三周/四周/永久保留；启动时与设置变更时自动按文件修改时间清理用户可见的历史日志目录，日志页显示当前保留策略。

#### 7. 社区标准与工程
- 补齐行为准则、安全策略、PR 模板、无障碍声明，修正 README 孤立标签并补交叉引用；
- 清理零引用导入与未使用样式；全库 lint 错误清零。
