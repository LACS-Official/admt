# 玩机管家 (ADMT) v1.5.5 更新日志

本次更新重点完成 **命令行交互能力的完整闭环**：在应用内引入基于 ConPTY 的真终端，补齐 PowerShell / CMD 的交互输入、复制与全文查找，并为 ADB / Fastboot / PowerShell / CMD 四个模式统一带来 Tab 补齐、自动联想与历史指令；同时打通 **ROM 中心小米官方实时索引链路**、**网盘分享链接浏览器直开**，并对软件商店与 ROM 中心进行极简视觉重构，彻底修复非直链下载把网页内容误存为安装包的缺陷。

---

### 🚀 新增功能

#### 1. 应用内置交互式终端（ConPTY / xterm.js）
- **真终端会话**：PowerShell / CMD 模式由一次性指令执行升级为常驻 PTY 会话，新增 `pty_create`、`pty_write`、`pty_resize`、`pty_close`、`pty_list` 五组后端命令与输出/退出事件；原始字节经 base64 传输，避免 UTF-8 截断，窗口缩放实时同步终端尺寸；
- **完整 shell 行为**：保留 PSReadLine 命令行编辑、`Ctrl+C` 中断、命令回显与提示符，`ssh` 密码输入、主机密钥确认等交互不再被迫弹独立窗口；`ssh / sftp / telnet` 会话型命令自动送入当前终端执行，其余平台给出明确引导而非静默挂起；
- **MCP 自动化隔离**：无界面的工具调用显式关闭交互会话分支，避免自动化执行时静默弹出终端窗口；
- **查找与复制**：新增全文查找（区分大小写、正则、上一个/下一个、`当前 / 总数` 计数、深浅主题高亮）、选中复制与一键复制全部输出（含 8000 行回滚区、自动合并换行续行）、浮动复制按钮与右键菜单；快捷键 `Ctrl+Shift+F` 开关查找、`F3 / Shift+F3` 跳转、`Ctrl+Shift+C / V` 复制粘贴，原有 `Ctrl+C` 仍为 shell 中断。

#### 2. 四大命令行模式统一支持智能输入
- **Tab 补齐与自动联想**：输入即弹出候选，来源依次为「历史指令 → 内置常用命令 → 当前模式快捷命令库」，`Tab / Shift+Tab` 循环补齐，连续按不会把候选越筛越短；支持鼠标采纳与 `Esc` 关闭；
- **上键调出上次指令**：历史按 ADB / Fastboot / PowerShell / CMD 四个模式分别持久化 50 条至本地存储，切换模式、关闭面板、重启应用均保留，`↓` 回退时恢复正在编辑的草稿；快捷命令库与 AI 注入执行的命令同样计入历史；
- **PTY 终端内联想**：交互终端跟踪当前输入行实时浮出候选，采纳时把剩余字符补发进会话并同步 shell 内部状态；无候选时放行给 PSReadLine / doskey 原生补齐，`↑ / ↓` 保持原版 shell 历史行为，回车执行的命令回写应用历史。

#### 3. ROM 中心接入小米官方实时索引
- **多源同步与离线兜底**：数据源按 GitHub API → jsDelivr 多节点（`testingcf / gcore / fastly / cdn`）→ raw → 本地离线缓存依次降级，索引缓存 30 分钟过期，页面显示同步日期、当前数据源健康状态与手动刷新入口，不再静默展示空列表；
- **动态机型与最新固件**：机型下拉由索引实时生成（实测覆盖 1300+ 机型），挂载后自动加载最新 60 条固件，默认全地区、移除二次地区过滤，补齐 K90 / Xiaomi 17 等新机并修正 K80 等代号映射；
- **权限放行**：`capabilities` 补齐 `api.github.com`、`xiaomirom.com` 与 jsDelivr 节点访问范围。

#### 4. 网盘分享链接自动转浏览器打开
- **四层识别**：前端工具、UI、资源服务与 Rust 下载后端统一识别夸克网盘、123 云盘、百度网盘关键字（含中文别名与常见短链域名），命中后返回 `NETDISK_REDIRECT_REQUIRED` 并直接调起系统浏览器；
- **多重回退**：外部打开统一走 URL 提取 + 插件回退链，主按钮在网盘场景下变为「在浏览器打开 XX 网盘」，且不受下载冷却限制。

### ⚡ 体验优化

#### 1. 软件商店下载路径收敛
- **卡片纯展示**：移除卡片上的「获取资源 / 运行 / 打开文件夹」等操作，整卡（含 `Enter / Space`）只负责打开详情弹窗，用户必须进入弹窗后才能发起下载，避免误触；

### 🛠️ 问题修复

#### 1. 非直链下载把 HTML 落地页写成安装包
- **根因**：下载后端仅按 URL 后缀推断文件名，网盘分享页与需要二次确认的落地页返回 `200 + text/html`，HTML 字节被直接写成 `.zip / .exe`，导致后续解压失败或产出假文件；
- **修复**：在 `download_and_extract`、`download_file`、`download_apk` 三条链路前置网盘关键字检测，并校验响应 `Content-Type`，命中时返回 `DOWNLOAD_PAGE_REQUIRED` 交由前端引导浏览器下载。

#### 2. ROM 中心列表为空 / 机型与固件陈旧
- 修复 WebView `fetch` 跨域限制、jsDelivr TLS 握手失败与 GitHub 未认证 API 限流导致的静默空列表，改为原生 HTTP 插件 + 多节点降级 + 本地缓存；
- 修复详情页解析正则不适配官方索引、YAML 日期字段类型处理，以及重复地区过滤导致结果被清空的问题；移除静默 `catch(() => [])`，数据源异常可被感知。

#### 3. 交互细节修复
- 修复查找插件以「临时选中」标记当前匹配项，导致一键复制误复制匹配词而非用户选中内容的问题；
- 修复 ROM 卡片调用了不存在的 `invoke("open_external_url")`，统一改用 `plugin-opener`；
- 修复详情弹窗在网盘链接下仍走下载冷却、以及下载失败后活跃任务残留的问题。
