# 玩机管家 (ADMT) v1.5.5 更新日志

## 新增
- 应用内置交互式终端（ConPTY / xterm.js）：常驻 PowerShell / CMD 会话、复制与全文查找。
- 四大命令行模式统一支持 Tab 补齐、自动联想与按模式持久化的历史指令。
- ROM 中心接入小米官方实时索引，多源降级与本地缓存。
- 网盘分享链接自动转系统浏览器打开。

## 优化
- 软件商店卡片改为纯展示，下载统一在详情弹窗内发起。
- 在线资源与 ROM 中心视觉统一，遵循极简规范。

## 修复
- 修复非直链下载把 HTML 落地页误存为安装包的问题。
- 修复 ROM 中心空列表、机型与固件陈旧、解析正则不适配等问题。
- 修复查找插件误复制匹配词、ROM 卡片错误调用与下载失败残留。
