# 玩机管家 (ADMT) v1.5.4 更新日志

本次更新重点推进 **AI 玩机助手与 MCP 工具生态全链路升级**、**上线全局快捷指令面板 (Spotlight, Ctrl+K)**、**打通本机终端 (PowerShell / CMD) 与多环境快捷命令库**，同时重构了按键映射与低延迟交互架构、上线全局下载动效与生命周期状态栏体系，全面修复了系统主题自动同步与托盘菜单冲突，并彻底完成**开源纯净化重构与大文件瘦身**。

---

### 🚀 新增功能

#### 1. AI 玩机助手与原生 MCP 扩展体系深度进化
- **内置原生 MCP Server 与 10 项核心工具调用**：全面接入 Model Context Protocol (MCP) 规范，AI 助手已打通原生 Tool Calling 能力，可自主调用 `admt_get_devices`（设备状态）、`admt_execute_adb`（ADB 调试）、`admt_execute_fastboot`（引导刷机）、`admt_reboot_device`（多模式重启）、`admt_take_screenshot`（屏幕截取）、`admt_execute_host_command`（宿主命令执行）等 10 项原生控制指令；
- **腾讯云元宝搜索 (WSA / SearchPro) 实时联网接入**：新增元宝搜索服务底层驱动，支持在诊断疑难故障或查询最新机型 ROM 时自动执行联网搜索，并内置极速版/标准版自动降级重试机制；
- **全气泡独立复制与单行克制头部**：重构 AI 对话面板，每个问答气泡均配备单色一键复制按钮；顶部配置栏浓缩为 Apple 极简 Mode 胶囊菜单，在任何窗口尺寸下均保持单行排布，消除折行与冗余开关。

#### 2. 全局快捷指令面板 (Spotlight / Command Palette, 快捷键 `Ctrl+K`)
- **秒级直达全局功能**：借鉴 macOS Spotlight / Craft 交互设计，随时按下 `Ctrl+K`（或 `Cmd+K`）唤出 16px Squircle 连续平滑圆角毛玻璃搜索浮层；
- **四大核心指令维度**：
  - **快捷操作**：支持一键截屏保存、设备重启（系统/Recovery/Bootloader）、深浅外观切换、侧边栏折叠、无线调试配对、复制设备序列号；
  - **设备快速切换**：动态展示当前已连接的所有 Android 设备，点击或回车即可即时切换当前操作目标；
  - **专区与二级功能导航**：快速跳转主页概览、应用管理、屏幕投屏、文件传输、设备按键控制、Fastboot 刷机专区、玩机资源与软件设置；
  - **终端与诊断工具**：快速唤起命令行窗口、日志管理器与 AI 助手；
- **全键盘流畅操作**：支持中英文全称与拼音首字母模糊匹配（如 `tp` 投屏、`jt` 截屏、`cq` 重启、`zd` 终端），支持 `↑ / ↓` 切换、`Enter` 执行与 `Esc` 退出。

#### 3. 命令行工具增加「本机终端（PowerShell / CMD）」模式
- **免连接设备宿主模式**：支持脱离安卓设备独立运行，直接在 ADMT 内切换至 `POWERSHELL` 或 `CMD` 模式，设备指示器自动显示为“本地主机 (Windows 宿主环境)”；
- **前缀自适应剥离与版本回退**：自动剥离用户输入的 `powershell`、`cmd` 等前缀；若输入空命令自动回退安全环境检测（PowerShell 运行 `$PSVersionTable.PSVersion`，CMD 运行 `ver`）；
- **四大 Tab 独立快捷命令库**：彻底移除冗余的 SSH 模式，ADB、FASTBOOT、POWERSHELL、CMD 每个 Tab 独立绑定专属快捷命令库，支持新增、编辑、删除与持久化保存，内置涵盖网络诊断、进程分析、系统软硬件检测等数十条实用预设。

#### 4. 投屏按键映射工作室 (Beta)
- **键位映射与连点支持**：投屏专区新增按键映射工作台，支持自定义键盘映射到触控屏幕点位，支持方向轮盘 (WASD)、按键单点、高频连点及滑动操作；
- **预设方案导入与导出**：内置针对主流手游与应用的配置方案，支持将按键配置快速导出备份为 JSON 文件或通过剪贴板一键共享；
- **输入通道自由切换**：支持 Windows 窗口消息极速直连与 ADB 流式下发，适应不同窗口与投屏场景。

#### 5. 全局动态下载进度胶囊
- **实时传输反馈**：底部状态栏新增全局微胶囊下载动效，支持实时展示下载百分比、下载速率（KB/s、MB/s）及平滑过渡贝塞尔进度条；
- **全流程状态提示**：下载中心、一键 Root 依赖包与第三方工具下载全链路打通，完成时提供单色对勾反馈与自动平滑离场，点击胶囊可直达下载中心。

### ⚡ 体验优化

#### 1. 深度对齐极简设计规范（去 AI 浮夸与说教式文案）
- **告别大段免责与惊悚红字**：移除了首页演示模式横幅，以及镜像分区刷写、小米线刷、小米解锁卡片中冗长刺眼的黄色/红色长篇警告；
- **状态栏生命周期绑定**：关键页面的提示与状态统一移至底部状态栏优雅展示，当离开对应卡片时自动清理，不污染全局主视觉；
- **操作确认聚焦客观参数**：Fastboot 分区擦除、镜像写入等高危操作统一改用紧凑的 Bento 弹窗，清晰列出即将执行的底层命令与受影响扇区，避免恐吓性话术；
- **功能文案降噪**：按键映射全面降噪为克制技术术语（如“连续点击”、“自动选择”），并标注文明清晰的 Beta 徽标；侧边栏顶部调整为克制精炼的“控制中心”。
- **可折叠侧边栏与开源 Star 入口**：左侧导航栏支持一键收起折叠（宽版 180px / 紧凑 60px 胶囊模式切换）；底部状态栏左侧增加低调的 GitHub Star 项目按钮。
- **纯净日志记录等级设置**：软件设置中的日志等级重构为 4 个极简 Fluent UI Switch 开关，移除冗余卡片与 emoji。

#### 2. 系统托盘右键菜单纯粹化
- 精简任务栏右键托盘菜单，移除容易误触的冗余重启指令，仅保留高频纯粹的「显示主页面」与「退出程序」，杜绝菜单抢占焦点与误操作。

#### 3. 捐赠墙与社区鸣谢多通道打通
- 优化了首次欢迎与设置中心的赞助支持入口，修复了系统 WebView 拦截外部网页导致捐赠墙无响应的问题；
- 点击后优先以毛玻璃动画唤出原生赞助弹窗，同时支持一键调起外部系统浏览器直达官方捐赠榜（`https://www.lacs.cc/donate`）。

#### 4. 架构开源治理与代码库瘦身
- **剔除闭源商业授权系统残留**：彻底清理了 `activation.rs`、`activationService.ts`、`ActivationExpiredHandler.tsx` 等数千行闭源商业与过期拦截代码，全局默认纯净开源；
- **大文件移除**：解除对 20MB 的二进制包与归档的 Git 索引跟踪，代码仓库体积大幅缩减。

### 🛠️ 问题修复

#### 1. Windows 本机控制台命令中文乱码彻底修复
- **根因修复**：Windows 本机命令行工具（如 `ping.exe`、`ipconfig.exe`、`netstat` 等）默认以 Windows OEM 控制台代码页（如 CP936 / GBK）输出字节流，导致 `String::from_utf8_lossy` 产生乱码；
- **内核级解码**：Rust 后端新增 `decode_process_output` 引擎，优先验证合法 UTF-8，当检测到非 UTF-8 字节流时自动调用 Windows 内核 API `MultiByteToWideChar(GetOEMCP(), ...)` 动态解码为标准 Unicode，彻底根治乱码。

#### 2. AI 玩机助手模型与参数校准 (Fix #2: Remove default model, set default temperature to 1.1)
- **修复默认模型失效问题**：移除了早已下线退役的默认 `gpt-3.5-turbo` 模型占位，升级为由用户自主选填/拉取最新模型列表，并兼容老版本残留配置平滑升级；
- **校准生成采样温度**：将初始采样温度从过于发散的旧参数校准为更契合现代大模型（如 GPT-4o / Claude 3.5 / DeepSeek V3）逻辑推理与命令生成的默认温度（1.0 ~ 1.1）；
- **强化流式推理与工具调用**：全面接入 SSE 流式传输，打通模型原生 Tool Calling 机制，修复了特定网络拦截时无法获取模型列表的问题。

#### 3. 显示设置「跟随系统改变主题」失效修复
- 修复了此前在设置中开启“跟随系统”后，应用无法自动获取 Windows 系统深浅模式变更的 Bug；
- 新增“注册表直读 + 窗口 API + 媒体查询”三级精准探测通道，保证系统切换夜间/浅色模式时即时无缝变色。
