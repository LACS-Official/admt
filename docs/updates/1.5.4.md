# 玩机管家 (ADMT) v1.5.4 更新日志

本次更新重点推进**开源架构纯净化重构**、**系统原生管理员提权支持**、**Root 镜像注入强化**以及**全面剔除虚假数据与闭源商业残留**，带来更加克制、透明、丝滑的极简玩机体验。

---

### 🚀 重点升级与新特性

#### 1. 系统底层权限与 Windows UAC 提权打通
- **真实管理员权限检测**：Rust 侧原生接入系统权限探测接口（`is_admin`），精确判断当前应用是否具备 Windows 管理员提升令牌；
- **一键 UAC 提权重启**：实现 `restart_as_admin` 命令，支持在需要高权限操作（如注册表写入、特定设备端口监听）时，优雅拉起 UAC 授权窗口并无缝重启当前应用；
- **注册表自启动配置读取**：实现 `get_autostart_config`，通过 Windows 注册表直读 Run 启动项，修复此前自启动状态判定失败的缺陷。

#### 2. Root 专区 Boot 镜像真实注入与 GKI 架构智能感知
- **Magisk 真实 Ramdisk 注入**：重构了底层 `patch_magisk` 镜像修补逻辑，解包后自动从 APK 提取 `magiskinit` 并调用 `magiskboot cpio ramdisk.cpio "add 0750 init magiskinit"` 执行底层注入，生成真正可用的 `boot_patched.img`；
- **GKI 2.0 架构智能提醒**：针对搭载高通骁龙 8+ Gen1 / 8 Gen2 / 8 Gen3 等 Android 13/14+ 新设备，修补面板新增智能检测机制，友好引导用户修补 `init_boot.img` 分区，杜绝误刷普通 boot 导致卡米变砖；
- **脱机纯本地安全模式**：移除失效的在线修补依赖，全面聚焦 100% 离线脱机镜像修补，保障固件与系统安全。

#### 3. 小米线刷 Fastboot ARB (防回滚保护) 预检与硬件防变砖阻断
- **Fastboot 原生 ARB 等级探测**：新增 Rust 侧 `fastboot_get_anti_rollback` 与 `fastboot_get_var` 接口，在设备处于 Fastboot 模式时原生直读设备底层硬件 ARB 等级；
- **固件脚本 ARB 自动比对**：加载线刷目录后自动解析 `flash_all.bat` 中的 `CURRENT_ANTI_VER` 固件等级与目标型号；
- **硬件级变砖主动熔断拦截**：当检测到当前设备硬件 ARB 等级高于目标线刷包等级（降级高危操作）时，面板展示明确告警并主动禁用刷入按钮，杜绝误刷降级导致芯片熔丝熔断与永久变砖。

#### 4. 无线调试与网络配对体验提升
- **扫码配对兜底指引**：针对国内定制 ROM（澎湃 OS、MIUI、ColorOS 等）系统相机无法直接拉起 AOSP 配对窗口的现象，新增清晰的 6 位配对码降级指引与端口直连提示。

#### 5. 隐私保护与使用数据完全本地化
- **拒绝任何外部设备指纹收集**：彻底切断向外部服务器上报设备指纹与使用统计的网络请求；
- **本地使用习惯留存**：所有统计（使用频次、上次使用时间）仅保存在用户本地浏览器持久化存储（`localStorage`）中，数据绝不离机，充分捍卫开源软件用户的隐私权益。

### ⚡ 架构纯净化与开源治理

#### 1. 彻底剔除闭源商业授权系统残留
- **Rust 后端纯净化**：彻底删除了 `src-tauri/src/activation.rs`（共 551 行涉及云端验证机密、防重放攻击与机器码锁定的闭源代码），应用全局默认免激活；
- **修复过期拦截与白屏异常**：彻底移除了 `ActivationExpiredHandler` 与 `UserInfoModal` 组件，消除了此前点击“输入新激活码”可能引发的整屏渲染白屏 Bug；
- **网络路由净化**：在前端 API 配置中完全剥离了所有激活码云端管理接口定义。

#### 2. 真实数据规范：清除 Math.random() 假数据
- **投屏性能指标真实化**：移除了 `screenMirrorService` 中利用 `Math.random()` 伪造帧率、码率、延迟与丢包率的占位逻辑；
- **明确状态反馈**：未打通底层硬件流统计前统一返回空状态并输出明确的技术状态提示，遵循《ADMT 设计与开发规范》中真实、克制的人工工匠精神。

#### 3. 仓库体积与冗余大幅瘦身
- **移除版本跟踪中的二进制大文件**：从 Git 索引中彻底解除对 `output/ADMT_玩机管家_V1.2.0.exe`（20.1 MB）及 `src-tauri/tools/scrcpy*.zip/*.tar.gz`（20.1 MB）的追踪，使代码仓库轻盈敏捷；
- **清理僵尸文件**：移除了未被引用的僵尸脚本与模拟数据文件，降低构建体积与维护成本。
