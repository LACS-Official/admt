# 玩机管家 (ADMT) v1.5.4 更新日志

## 新增
- AI 助手接入原生 MCP 工具调用（10 项设备/命令能力）与元宝联网搜索。
- 全局快捷指令面板：`Ctrl+K` 唤出，支持拼音匹配、设备切换与专区跳转。
- 命令行新增本机 PowerShell / CMD 模式，四大模式各有独立快捷命令库。

- 移除闭源授权残留与大体积二进制文件，完成开源净化与仓库瘦身。
