# 玩机管家 (ADMT) v1.5.1 更新日志

###  核心新特性与深度升级

#### 1.  Fastboot 可视化分区管理系统
- **动态设备分区探测与智能感知**：
  - 自动识别当前连接 Fastboot / Fastbootd 设备的全部物理与逻辑分区（结合 `fastboot getvar all` 动态探测与 Android 核心分区预设）；
  - 修复底层双冒号分区名/尺寸解析器，精确读取所有分区的实际字节大小、文件系统类型及 A/B Slot 槽位归属；
  - 支持 **A/B Slot 实时状态识别** 与 **一键切换活动槽位**（`fastboot set_active a/b`），轻松实现救砖与回滚；
  - 针对系统开机 (ADB) 模式提供醒目状态条与一键重启至 Fastboot 模式引导。
- **内置多选框与批量控制**：
  - 分区列表每行内置独立 `Checkbox` 复选框，支持按分类一键全选/反选与选择计数；
  - **批量提取 (Batch Fetch)**：勾选多个分区后，一键顺序拉取并导出所有选中分区的镜像文件至指定目录；
  - **批量擦除 (Batch Erase)**：支持批量安全擦除勾选分区（集成多重危险二次确认）。
- **单分区精细化直接联动**：
  - 单击任一分区行即可直接锁定目标分区，无需反复手动输入或二次下拉选择；
  - **镜像刷入**：直接选择待刷入的本地镜像文件，一键刷入至目标分区（支持 Slot 及 DM-Verity / AVB 禁用参数配置）。

---

#### 2.  独立一键解包与一键解析双引擎
- ** 一键解包当前分区 (Unpack)**：
  - 直接针对选中的分区（如 `boot`, `init_boot`, `vendor_boot`, `vbmeta` 等），自动从设备提取镜像并调用底层 Rust 引擎进行二进制结构真实解包；
  - 自动拆解并导出组件：
    - `kernel`（内核本体）
    - `ramdisk.img` 与 `ramdisk.cpio`（解压后的 Ramdisk 文件系统）
    - `dtb.img`（设备树）
    - `boot_info.txt` 与 `cmdline.txt`（内核启动命令行与头部元数据规格）；
  - 解包产物自动归档保存至用户选定的输出文件夹中。
- ** 一键解析当前分区 (Inspect)**：
  - 自动提取目标分区镜像并进行底层二进制逆向分析；
  - **Android Boot Header (v0~v4)**：精确解析 Header Version、OS Version（如 Android 14.0.0）、安全补丁级别（OS Patch Level，如 2024-05）、内核/Ramdisk/DTB 规格与完整 CMDLINE；
  - **Ramdisk 智能解压与 Root 指纹探测**：解压 cpio/gzip 数据流，深度搜索识别 **Magisk (`magiskinit`, `.magisk`)**、**KernelSU (`kernelsu`, `ksud`)**、**APatch (`apatch`, `superkey`)** 补丁指纹，并从 Ramdisk 中逆向提取 `build.prop` / `default.prop` 系统属性；
  - **AVB 2.0 / Vbmeta 签名校验解析**：解析 Magic `AVB0`、防回滚版本 (`Rollback Index`)、DM-Verity 禁用状态与 AVB 签名验证状态；
  - **AI 智能专家诊断报告与实时多轮问答**。

---

#### 3.  在线软件资源：弹窗与管理内一键直接运行启动程序
- **资源详情弹窗直接启动**：
  - 在【在线资源 - 软件详情】弹窗中，当软件下载解压完成后，底部直接呈现 **「 运行程序」** 主操作按钮；
  - 弹窗内新增 **「启动程序 / 执行入口」** 专属卡片，展示开发者配置的执行文件名（`openname`），并支持在卡片内直接一键唤醒运行；
- **智能可执行文件匹配引擎**：
  - 后端 Rust 引擎智能感知解压目录：优先读取 `openname` 及 `lacs_config.json`，次级自动智能检索目录内的主启动程序（`.exe`, `.bat`, `.cmd`），并自动以正确的所属工作目录启动，杜绝路径丢失导致的闪退；
- **全链路启动支持**：
  - 资源卡片（SoftwareCard）与下载管理任务列表（DownloadManagerPanel）中同样支持已完成任务的一键「运行」启动。

---

#### 4.  首页硬件实时监控展示逻辑优化
- **仅在系统模式（System Mode）下展示与轮询**：
  - 当设备处于 Fastboot、Recovery、Sideload 或断开连接等非系统开机模式时，首页自动隐藏硬件实时监控卡片；
  - 内部自动停止 ADB 硬件指标轮询与日志查询，避免在 Fastboot/Recovery 模式下无效报错与占用后台 CPU 资源。

---

#### 5.  原生系统托盘与右键菜单深度优化
- **修复托盘右键菜单唤出冲突**：
  - 修复此前鼠标右键点击托盘图标时触发全局点击事件导致主窗口被强制唤醒并抢焦冲掉菜单的问题；
  - 明确区隔鼠标事件：**左键单击/双击** 控制主窗口显示与最小化切换，**右键单击** 专属调出原生系统托盘菜单；
- **托盘菜单功能与事件直通**：
  - 重构托盘菜单绑定机制，使用标准 `MenuItem::with_id` 显式标识事件并直通前端事件总线；
  - 新增快捷操作项：**显示主界面**、**重启设备至系统**、**重启至 Fastboot 模式**、**重启至 Recovery 模式** 及 **退出玩机管家**。
