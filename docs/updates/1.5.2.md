# 玩机管家 (ADMT) v1.5.2 更新日志

本次更新带来多品牌官方系统固件下载中心、精选在线 Root 模块库与一键更新检测，全面重构了硬件实时状态监控与频率自定义，并针对澎湃 OS 版本识别、赞赏支持排版以及全界面视觉细节进行了深度优化与修复。

---

### 新增功能

#### 1. 多品牌官方系统固件 (ROM) 下载中心
- **主流品牌全覆盖**：在刷机专区新增多品牌系统固件下载服务，支持小米、OPPO、一加、真我、类原生 (AOSP/Pixel) 等主流品牌机型；
- **智能多维度筛选**：支持按机型代号、发行地区（国行、国际版、欧洲版等）、系统分支（稳定版、开发版/测试版）精准查找对应的系统完整包与线刷包；
- **服务线路自由切换**：提供官方源与镜像加速线路一键切换，支持直接下载并完整查看官方版本更新说明。

#### 2. 精选在线 Root 模块库与一键版本检查
- **模块生态全面兼容**：模块管理界面全面支持检测与管理 LSPosed、KernelSU 以及 Magisk 模块；
- **精选在线模块仓库**：内置收录 LSPosed Mod、Zygisk Next、Shamiko、Tricky Store 等高频热门实用模块，支持一键在线下载安装、直链复制与浏览器查看；
- **一键联网检查更新**：已安装模块支持与在线库比对并一键检测新版本；同时支持直接粘贴第三方在线直链快速刷入模块。

#### 3. 设备硬件状态卡片独立实时自动刷新
- **状态卡片独立监控**：首页概览顶部的 4 个硬件状态卡片（电池电量、设备温度、存储空间、运行内存）支持独立自动检测与刷新；
- **刷新频率随心调节**：卡片右上角新增快捷设置菜单，支持一键开启/关闭自动刷新，并自由切换刷新间隔（2 秒 / 3 秒 / 5 秒 / 10 秒 / 30 秒），或随时点击按钮立即刷新；
- **底层指标精准读取**：实时监测电池健康度、充电状态、芯片温度与 RAM/ROM 实际使用容量，动态反映设备运行状态。

#### 4. 设备软硬件配置 HTML 全景报告导出
- **直观导出按钮**：设备概览顶部操作栏新增显式的「HTML 报告」功能按钮；
- **一键生成精美报告**：点击即可快速导出包含设备基本信息、屏幕规格、处理器架构、系统安全状态与存储详情的精美离线网页报告，方便玩家与开发者分享配置或保存备份。

### 体验与视觉优化

#### 1. 全面统一界面主题色彩质感
- **告别杂乱色彩**：设备概览顶部的 4 个状态卡片、电源管理中心（系统/Recovery/Fastboot 重启）以及辅助工具卡片的图标、高亮底色和进度条，全面统一为低饱和度原生主题色，视觉层次更加专业、克制与统一；
- **控件圆角规范化**：严格遵循大连续平滑圆角（Squircle）与药丸胶囊（Pill）设计规范，提升操作触控与点击质感。

#### 2. 刷机专区与分区管理交互减负
- **移除界面阻断遮罩**：在未连接 Fastboot 模式时进入分区管理，不再强制弹窗遮挡整个工作区，用户可自由提前浏览核心分区列表、搜索分区或预先配置刷写参数；
- **操作级精准引导**：仅在点击执行具体的敏感操作（如镜像刷入、分区擦除、分区提取）时，智能弹出轻量操作引导与一键重启至 Fastboot 提示。

#### 3. 一键 Root 流程精炼
- 优化 Root 执行面板过渡动效，去除冗余的毛玻璃遮罩；
- 核心修补组件全面支持官方最新版本实时获取与国内高速下载。

#### 4. 侧边栏菜单精简聚焦
- 侧边栏导航暂时隐藏尚未完善的次级功能入口，让核心功能更醒目聚焦，提升日常高频搞机效率。

---

### 问题修复

#### 1. 小米澎湃 OS (HyperOS) 版本识别校准
- 修复此前在部分小米澎湃 OS 设备上，系统版本号被错误解析为老旧 MIUI 版本的问题，现在能准确识别并展示完整的 HyperOS 正式版本代号与增量版本信息。

#### 2. 赞赏支持弹窗排版与溢出修复
- 彻底重构了“关于我们 - 赞赏支持”弹出视窗的排版布局，采用自适应双列结构；
- 修复了在部分分辨率或窗口缩放下文字挤压变形、二维码显示不全以及多层滚动条异常的问题，界面整洁舒展。

#### 3. 软件商店资源链接校准
- 全面修正了在线资源与扩展软件的官方服务节点与详情跳转地址，保障下载与访问稳定通畅。

#### 4. 系统托盘右键菜单冲突修复
- 修复了此前在 Windows 任务栏右键点击托盘图标时，主窗口强制唤醒抢夺焦点导致托盘右键菜单闪退的问题；
- 规范事件响应：左键单击或双击切换主窗口，右键专注呼出原生快捷托盘菜单。
