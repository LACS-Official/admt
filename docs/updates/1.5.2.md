# 玩机管家 (ADMT) v1.5.2 更新日志

## 新增
- 多品牌官方 ROM 下载中心：覆盖小米、OPPO、一加、真我、AOSP，支持机型/地区/分支筛选与镜像加速。
- 在线 Root 模块库：兼容 LSPosed / KernelSU / Magisk 模块，支持在线下载安装与版本检查。
- 硬件状态卡片独立自动刷新，间隔 2/3/5/10/30 秒可调。
- 一键导出设备软硬件配置 HTML 报告。

## 优化
- 统一主题配色与控件圆角；分区管理移除阻断遮罩，改为操作级引导。
- 一键 Root 面板去除毛玻璃遮罩，支持官方组件实时获取与国内高速下载。
- 侧边栏暂时隐藏尚未完善的次级入口。

## 修复
- 修复小米 HyperOS 版本被误识别为 MIUI 的问题。
- 修复赞赏支持弹窗排版挤压、二维码显示不全与多层滚动异常。
- 校准在线资源官方链接；修复托盘右键菜单与主窗口抢焦冲突。
