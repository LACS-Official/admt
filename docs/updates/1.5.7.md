# 玩机管家 (ADMT) v1.5.7 更新日志

## 新增
- macOS 与 Linux 桌面版，Windows / macOS / Linux 三平台统一构建发布。
- 应用内自动更新：检查到新版本后直接下载、安装并自动重启完成升级。
- 无线调试扫码配对闭环：扫码后自动发现设备、自动配对并连接，无需先插 USB 线。
- Web 版历史日志持久化，跨会话回看。

## 优化
- 无线调试弹窗重构为「扫码配对 / IP 连接 / 手动配对」三标签页，单表单聚焦、文案精简。
- 启动时记录运行系统平台，使用统计补齐 OS 维度。
- 更新弹窗展示下载进度；上游无更新包时自动回退官网下载。
- 双端能力对照文档同步更新（Fastboot 刷写等已实现能力标注）。

## 修复
- 修复无线配对信息序列化错误，配对码与二维码恢复正常显示。
- 修复无线调试界面深色模式硬编码色值与错误的关闭按钮图标。
