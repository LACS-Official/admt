## 📱 产品概述

**玩机管家**是一款基于Tauri 2.0架构的新一代Android设备管理工具，采用Rust + React技术栈打造。专为Android开发者、设备调试人员、技术研究者和数码爱好者量身定制，通过现代化的图形界面集成强大的ADB/Fastboot工具链，实现专业级设备管理功能。

### 🎯 产品定位

| 维度       | 描述                               |
| -------- | -------------------------------- |
| **核心用户** | Android开发工程师、QA测试工程师、安全研究员、刷机爱好者 |
| **价值主张** | 专业工具平民化，复杂操作简单化，提升设备管理效率300%     |
| **技术定位** | 基于现代化架构的专业级Android设备管理解决方案       |
| <br />   | <br />                           |

### ✨ 核心价值

- **一站式管理**: 从设备连接，到应用管理、投屏调试、镜像刷机，一条龙服务
- **性能卓越**: Rust内存安全，运行流畅，资源占用低
- **跨平台支持**: Windows/macOS/Linux 多平台覆盖

## 🚀 核心功能架构

### 1. 智能设备管理中心 📊

| 功能         | 描述                           |
| ---------- | ---------------------------- |
| **实时设备扫描** | 2秒间隔自动检测，支持ADB/Fastboot双模式识别 |
| **多设备并发**  | 同时管理32台设备，支持设备连接统计和历史追踪      |
| **深度设备信息** | 60+系统属性获取，包括CPU、内存、存储、网络配置   |
| **设备状态监控** | 实时电量、温度、性能监控，支持图表化展示         |
| **连接稳定性**  | 智能重连机制，连接中断自动恢复              |

### 2. 企业级文件管理 📁

| 功能         | 描述                  |
| ---------- | ------------------- |
| **高性能传输**  | 支持大文件断点续传，传输速度提升40% |
| **智能文件浏览** | 类似资源管理器的目录导航，支持文件预览 |
| **批量操作**   | 支持多文件选择、拖拽上传、批量下载   |
| **传输队列**   | 可视化进度管理，支持暂停/恢复/取消  |

### 3. 专业ADB工具链 🔧

| **批量执行**    | 支持多设备同时执行相同命令      |

| **执行历史**    | 完整的操作审计和回放功能       |

## 🔧 技术特性

### ADB命令支持

| 分类       | 命令示例                                                         |
| -------- | ------------------------------------------------------------ |
| **设备信息** | `adb devices`, `adb shell getprop *`, `adb shell dumpsys`    |
| **文件操作** | `adb push`, `adb pull`, `adb shell ls/mkdir/rm`              |
| **应用管理** | `adb install`, `adb uninstall`, `adb shell pm list`          |
| **系统控制** | `adb reboot recovery/fastboot/bootloader`, `adb shell input` |
| **日志输出** | `adb logcat`, `adb shell dumpsys`                            |

### Fastboot命令支持

| 分类       | 命令示例                                              |
| -------- | ------------------------------------------------- |
| **设备信息** | `fastboot devices`, `fastboot getvar all`         |
| **镜像刷写** | `fastboot flash boot/recovery/system */*.img`     |
| **解锁**   | `fastboot oem unlock`, `fastboot flashing unlock` |
| **重启**   | `fastboot reboot`, `fastboot reboot recovery`     |

### Scrcpy投屏特性
