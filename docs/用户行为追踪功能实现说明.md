# 用户行为追踪功能实现说明

## 概述

根据 API 使用指南文档 `docs\API_USAGE_GUIDE.md` 中的规范，实现了用户行为追踪功能，包括：

1. **软件使用记录API** (`/api/user-behavior/usage`)：用户进入主页面时自动发送使用数据
2. **设备连接API** (`/api/user-behavior/device-connections`)：检测到新设备连接时自动发送连接信息

两个API都无需API Key认证，实现了IP级别的频率限制，并严格遵循隐私政策要求。

## 功能特性

### 1. 隐私保护优先
- ✅ 仅在用户同意隐私政策后发送数据
- ✅ 检查用户是否已完成隐私设置
- ✅ 验证用户是否允许收集用户行为数据
- ✅ 遵循最小化数据收集原则

### 2. 会话管理
- ✅ 每个应用会话只发送一次数据
- ✅ 避免重复发送造成的数据污染
- ✅ 支持会话重置（用于测试）

### 3. 无认证访问
- ✅ 软件使用记录API无需API Key认证
- ✅ 设备连接API无需API Key认证
- ✅ 支持请求超时和错误处理
- ✅ 实现IP级别频率限制（10秒）

### 4. 设备指纹生成
- ✅ 生成唯一设备标识符
- ✅ 基于系统信息的哈希算法
- ✅ 备用指纹生成方案

## API 调用规范

### 软件使用记录API

**请求端点**
```
POST /api/user-behavior/usage
```

**认证要求**: 无需认证

**频率限制**: 同一IP地址在10秒内只能访问一次

**请求头**
```http
Content-Type: application/json
```

**请求体**
```json
{
  "softwareId": 1,
  "softwareName": "玩机管家",
  "softwareVersion": "1.0.0",
  "deviceFingerprint": "fp_1234567890abcdef",
  "used": 1
}
```

**响应格式**
```json
{
  "success": true,
  "data": {
    "softwareId": 1,
    "deviceFingerprint": "fp_1234567890abcdef",
    "usedAt": "2025-08-19T10:00:00.000Z"
  },
  "message": "使用记录成功"
}
```

### 设备连接记录API

**请求端点**
```
POST /api/user-behavior/device-connections
```

**认证要求**: 无需认证

**频率限制**: 同一IP地址在10秒内只能访问一次

**请求头**
```http
Content-Type: application/json
```

**请求体**
```json
{
  "deviceSerial": "SM-G991B-123456789",
  "softwareId": 1,
  "userDeviceFingerprint": "fp_1234567890abcdef",
  "deviceBrand": "Samsung",
  "deviceModel": "Galaxy S21",
  "osVersion": "Android 11"
}
```

**响应格式**
```json
{
  "success": true,
  "data": {
    "id": "uuid-456",
    "deviceSerial": "SM-G991B-123456789",
    "softwareId": 1,
    "createdAt": "2025-08-19T10:00:00.000Z"
  },
  "message": "设备连接记录已保存"
}
```

### 频率限制
- 两个API都实现IP级别频率限制：同一IP地址10秒内只能成功响应一次请求
- 超出限制返回429状态码和Retry-After头部

## 隐私政策集成

### 前置条件检查
```typescript
private canCollectData(): boolean {
  const privacyStore = usePrivacyConsentStore.getState();
  
  // 检查用户是否已完成隐私设置并同意数据收集
  const hasConsent = privacyStore.hasCompletedPrivacySetup &&
                    privacyStore.hasAcceptedPrivacyPolicy &&
                    privacyStore.hasAcceptedUserAgreement &&
                    privacyStore.hasAcceptedDataCollection;

  // 检查是否允许收集用户行为数据
  const canCollectBehavior = privacyStore.canCollectUserBehavior();

  return hasConsent && canCollectBehavior;
}
```

### 数据收集类型
- `deviceData`: 设备信息数据 ✅ (设备连接记录需要)
- `userBehavior`: 用户行为数据 ✅ (软件使用记录需要)
- `analytics`: 匿名分析数据
- `crashReporting`: 崩溃报告
- `performanceMetrics`: 性能指标

## 错误处理

### 1. 网络错误
- 10秒请求超时
- 静默失败，不影响用户体验
- 错误日志记录

### 2. 权限错误
- 检查隐私政策同意状态
- 跳过数据发送，记录日志
- 不显示错误提示

### 3. 设备指纹生成失败
- 使用备用指纹生成方案
- 基于浏览器信息生成简单指纹
