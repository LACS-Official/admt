# 用户行为追踪功能实现说明

## 概述

根据 API 使用指南文档 `docs\API_USAGE_GUIDE.md` 中的规范，实现了用户行为追踪功能。该功能在用户同意隐私政策条款后，当用户每次进入应用的工具主页面时，自动发送使用数据到后端API。

## 功能特性

### 1. 隐私保护优先
- ✅ 仅在用户同意隐私政策后发送数据
- ✅ 检查用户是否已完成隐私设置
- ✅ 验证用户是否允许收集用户行为数据
- ✅ 遵循最小化数据收集原则

### 2. 会话管理
- ✅ 每个应用会话只发送一次数据
- ✅ 避免重复发送造成的数据污染
- ✅ 支持会话重置（用于测试）

### 3. 安全传输
- ✅ 使用安全配置管理API Key
- ✅ API Key安全存储在Tauri后端
- ✅ 支持请求超时和错误处理

### 4. 设备指纹生成
- ✅ 生成唯一设备标识符
- ✅ 基于系统信息的哈希算法
- ✅ 备用指纹生成方案

## API 调用规范

### 请求端点
```
POST /api/user-behavior/usage
```

### 请求头
```http
Content-Type: application/json
X-API-Key: {安全存储的API密钥}
User-Agent: {应用ID}/{应用版本}
```

### 请求体
```json
{
  "softwareId": 1,
  "softwareName": "玩机管家",
  "softwareVersion": "1.0.0",
  "deviceFingerprint": "fp_1234567890abcdef",
  "used": 1
}
```

### 响应格式
```json
{
  "success": true,
  "data": {
    "softwareId": 1,
    "deviceFingerprint": "fp_1234567890abcdef",
    "usedAt": "2025-08-19T10:00:00.000Z"
  },
  "message": "使用记录成功"
}
```

## 隐私政策集成

### 前置条件检查
```typescript
private canCollectData(): boolean {
  const privacyStore = usePrivacyConsentStore.getState();
  
  // 检查用户是否已完成隐私设置并同意数据收集
  const hasConsent = privacyStore.hasCompletedPrivacySetup &&
                    privacyStore.hasAcceptedPrivacyPolicy &&
                    privacyStore.hasAcceptedUserAgreement &&
                    privacyStore.hasAcceptedDataCollection;

  // 检查是否允许收集用户行为数据
  const canCollectBehavior = privacyStore.canCollectUserBehavior();

  return hasConsent && canCollectBehavior;
}
```

### 数据收集类型
- `deviceData`: 设备信息数据
- `userBehavior`: 用户行为数据 ✅ (必需)
- `analytics`: 匿名分析数据
- `crashReporting`: 崩溃报告
- `performanceMetrics`: 性能指标

## 错误处理

### 1. 网络错误
- 10秒请求超时
- 静默失败，不影响用户体验
- 错误日志记录

### 2. 权限错误
- 检查隐私政策同意状态
- 跳过数据发送，记录日志
- 不显示错误提示

### 3. 设备指纹生成失败
- 使用备用指纹生成方案
- 基于浏览器信息生成简单指纹

## 安全配置

### API Key 存储
- 存储在 Tauri 后端 Rust 代码中
- 通过 `SecurityConfigManager` 管理
- 不暴露给前端 JavaScript
