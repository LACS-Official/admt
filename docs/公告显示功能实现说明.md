# 公告显示功能实现说明

## 🎯 功能概述

在版本检测完成后，自动获取并显示软件ID为1的最新公告信息，显示3秒后自动跳转到下一个页面。

## ✅ 实现的功能

### 1. **公告获取**
- 在版本检查的同时并行获取公告信息
- 使用软件ID为1获取公告（根据API文档要求）
- 获取最新的5条已发布公告，按发布时间降序排列

### 2. **公告显示逻辑**
- 版本检查完成后，如果有公告则显示公告内容
- 如果没有公告，直接跳转到下一个页面
- 公告显示在加载页面下方，不使用弹窗形式

### 3. **自动跳转机制**
- 显示公告后开始3秒倒计时
- 倒计时期间显示"X秒后自动跳转到下一步"提示
- 倒计时结束后自动进入下一个启动阶段

const [versionResult, announcementResult] = await Promise.all([

#### 2. **公告显示控制**
```typescript
// 如果有公告，显示公告并开始倒计时
if (announcementResult.length > 0) {
  setShowAnnouncements(true);
  setStatusMessage('正在显示最新公告...');
  startAnnouncementCountdown(versionResult);
} else {
  // 没有公告，直接进入下一个页面
  setTimeout(() => {
    onComplete(versionResult);
  }, 1000);
}
```

#### 3. **倒计时实现**
```typescript
const startAnnouncementCountdown = (versionResult: VersionCheckResult) => {
  let countdown = 3;
  setAnnouncementCountdown(countdown);
  
  const countdownInterval = setInterval(() => {
    countdown--;
    setAnnouncementCountdown(countdown);
    setStatusMessage(`正在显示最新公告... (${countdown}秒后自动跳转)`);
    
    if (countdown <= 0) {
      clearInterval(countdownInterval);
      setShowAnnouncements(false);
      onComplete(versionResult);
    }
  }, 1000);
};
```

### **公告API调用**
```typescript
const response = await announcementService.getAnnouncements({
  limit: 5,                    // 获取最新5条
  isPublished: true,           // 只获取已发布的
  sortBy: 'publishedAt',       // 按发布时间排序
  sortOrder: 'desc'            // 降序排列（最新的在前）
});
```

## 📱 用户体验

### **显示流程**
1. **版本检查阶段**：显示"正在检查版本更新..."
2. **检查完成**：显示版本检查结果
3. **公告显示**：如果有公告，显示"正在显示最新公告..."
4. **倒计时提示**：显示"X秒后自动跳转到下一步"
5. **自动跳转**：3秒后自动进入下一个启动阶段

### **公告展示样式**
- 公告显示在版本信息下方
- 包含公告图标、标题、内容预览
- 支持多种公告类型（一般、更新、安全、维护等）
- 支持优先级显示（低、普通、高、紧急）

### **错误处理**
- 如果公告获取失败，显示警告信息但不阻止应用启动
- 网络错误时返回空公告列表，直接跳转到下一步
- 确保应用启动流程的稳定性

## 🔍 API集成

### **使用的API端点**
```
GET /app/software/id/1/announcements
```

### **请求参数**
- `page=1` - 页码
- `limit=5` - 每页数量
- `type=all` - 公告类型
- `priority=all` - 优先级
- `isPublished=true` - 只获取已发布的
- `sortBy=publishedAt` - 按发布时间排序
- `sortOrder=desc` - 降序排列
