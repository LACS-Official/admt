# 禁用浏览器自带右键菜单的实现

## 问题描述
在发布版中禁用浏览器自带的右键菜单。

## 解决方案
项目中已有两个类实现了禁用右键菜单的功能：
1. `SecurityProtection` 类在 `src/utils/securityProtection.ts` 中
2. `DevToolsManager` 类在 `src/utils/devtools.ts` 中

这两个类都使用了单例模式，并且在生产环境下会自动禁用右键菜单。

## 实现步骤
1. 在 `main.tsx` 中导入 `securityProtection` 模块，确保在应用启动时加载 `SecurityProtection` 类。
2. 在 `main.tsx` 中导入 `devtools` 模块，确保在应用启动时加载 `DevToolsManager` 类。

## 代码更改
在 `src/main.tsx` 文件中添加以下导入语句：
```typescript
// 导入安全保护模块，确保在应用启动时加载
import "./utils/securityProtection";
import "./utils/devtools";
```

## 工作原理
1. `SecurityProtection` 类在构造函数中会自动调用 `init()` 方法，而 `init()` 方法会调用 `disableContextMenu()` 来禁用右键菜单。
2. `DevToolsManager` 类在构造函数中会自动调用 `setupDevTools()` 方法，而在生产环境下，`setupDevTools()` 方法会调用 `disableDevTools()` 方法，其中包含 `disableContextMenu()` 方法来禁用右键菜单。
3. 这两个类都会根据环境变量自动判断是否为开发环境，在开发环境下默认禁用保护，在生产环境下启用保护。

## 验证方法
在发布版中打开应用，尝试右键点击页面，应该无法看到浏览器自带的右键菜单。在开发环境下，右键菜单应该正常显示。
