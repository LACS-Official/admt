# 自动追踪调试指南

## 问题描述

用户行为追踪功能存在问题：只有在设置页面手动点击"测试发送使用数据"按钮后，使用数据才会正常发送到API。但是根据需求，应该在用户同意隐私政策条款后，每次进入应用主页面时自动发送使用数据。

## 调试步骤

### 第一步：检查主页面组件是否被加载

1. **打开应用并进入主页面**
2. **打开浏览器开发者工具 (F12)**
3. **切换到 Console 标签**
4. **查找以下日志**：
   ```
   🏠 HomePage useEffect 被触发
   🏠 HomePage组件已挂载，开始追踪主页面进入...
   🏠 当前时间: 2025-08-19T...
   🏠 组件挂载位置: HomePage.tsx useEffect
   ```

**如果没有看到这些日志**：
- 说明主页面组件没有被正确加载
- 检查路由配置是否正确
- 检查是否有其他组件覆盖了主页面

### 第二步：检查追踪服务调用

如果第一步的日志正常，继续查找：
```
🚀 trackMainPageEntry 方法被调用
🔧 服务未初始化，开始初始化... 或 ✅ 服务已初始化
📊 本会话尚未发送使用数据，继续检查...
```

**如果没有看到 `🚀 trackMainPageEntry 方法被调用`**：
- 说明 usageTrackingService.trackMainPageEntry() 没有被调用
- 检查导入是否正确
- 检查是否有异步错误

### 第三步：检查隐私政策状态

查找隐私政策检查日志：
```
🔍 详细的数据收集权限检查: {
  privacyStatus: {
    hasCompletedPrivacySetup: true/false,
    hasAcceptedPrivacyPolicy: true/false,
    hasAcceptedUserAgreement: true/false,
    hasAcceptedDataCollection: true/false,
    dataCollectionTypes: {...}
  },
  hasConsent: true/false,
  canCollectBehavior: true/false,
  finalResult: true/false
}
```

**如果 finalResult 为 false**：
- 检查哪个隐私政策字段为 false
- 使用设置页面的"调试隐私状态"按钮获取详细信息

### 第四步：检查安全配置初始化

查找安全配置相关日志：
```
✅ 安全配置初始化成功
📋 获取到安全配置: {
  api_base_url: "https://api-g.lacs.cc",
  software_id: 1,
  app_version: "1.0.0"
}
```

**如果看到安全配置初始化失败**：
- 检查 Tauri 后端是否正常运行
- 检查安全配置是否正确设置

### 第五步：检查设备指纹生成

查找设备指纹相关日志：
```
🔑 开始生成设备指纹...
🔑 设备指纹生成成功: fp_xxxxx...
🔑 设备指纹详细信息: {
  os: "windows",
  arch: "x86_64",
  hostname: "...",
  timestamp: 1234567890
}
```

**如果设备指纹生成失败**：
- 会自动使用备用方案
- 检查 Tauri 命令是否正确注册

### 第六步：检查数据发送

查找数据发送相关日志：
```
📤 准备发送使用数据: {
  softwareId: 1,
  softwareName: "玩机管家",
  softwareVersion: "1.0.0",
  deviceFingerprint: "fp_xxxxx...",
  used: 1
}
📤 发送使用数据到: https://api-g.lacs.cc/api/user-behavior/usage
✅ 使用数据发送成功，会话状态已更新
```

## 使用调试工具

### 设置页面调试功能

1. **进入设置页面**
2. **切换到"使用数据追踪"标签**
3. **使用以下调试按钮**：

#### 调试隐私状态
- 点击"调试隐私状态"按钮
- 查看控制台输出的完整隐私政策状态
- 确认所有必需的字段都为 true

#### 强制主页追踪
- 点击"强制主页追踪"按钮
- 这会重置会话状态并强制执行一次主页面追踪
- 观察是否能成功发送数据

#### 测试发送使用数据
- 点击"测试发送使用数据"按钮
- 这是手动触发的测试，如果这个能成功，说明API调用本身没问题

## 常见问题和解决方案

### 问题1：隐私政策未正确同意

**症状**：看到 `🚫 用户未同意数据收集，跳过使用数据发送`

**解决方案**：
1. 重新启动应用
2. 在隐私政策对话框中确保勾选所有必需的选项
3. 点击"同意并继续"
4. 使用"调试隐私状态"按钮验证状态

### 问题2：会话状态异常

**症状**：看到 `📊 本会话已发送过使用数据，跳过重复发送`，但实际上没有发送

**解决方案**：
1. 使用"强制主页追踪"按钮重置会话
2. 或者重新启动应用

### 问题3：安全配置问题

**症状**：看到安全配置相关错误

**解决方案**：
1. 检查 Tauri 应用是否正常启动
2. 检查后端配置是否正确
3. 重新启动应用

### 问题4：网络连接问题

**症状**：看到网络请求失败的错误

**解决方案**：
1. 检查网络连接
2. 检查 API 端点是否可访问
3. 检查防火墙设置

## 最新修复措施

我已经实施了以下修复措施来解决自动追踪问题：

### 1. 增强的调试日志
- 在 `usageTrackingService.ts` 中添加了详细的调试信息
- 在 `HomePage.tsx` 中添加了组件挂载日志
- 在 `MainContent.tsx` 中添加了备用追踪逻辑

### 2. 双重追踪保障
- **主要追踪**: HomePage组件挂载时立即执行
- **备用追踪**: MainContent组件挂载2秒后执行（避免重复）

### 3. 新增调试工具
在设置页面的"使用数据追踪"标签中新增：
- **检查应用状态**: 输出当前应用的详细状态信息
- **调试隐私状态**: 显示完整的隐私政策同意状态
- **强制主页追踪**: 重置会话并强制执行追踪
