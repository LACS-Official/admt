# 外部工具目录

运行时代码固定从 `tools/adb-bin`、`tools/lacs`、`tools/scrcpy` 读取，因此这三个根目录是「当前生效目录」，不要改名。

- `adb-bin/`、`lacs/`、`scrcpy/`：当前生效目录，Windows 基线二进制保留在这里。
- `windows/`、`macos/`、`linux/`：平台源目录。构建前由 `scripts/prepare-tools.mjs` 按当前系统把对应平台源目录覆盖到上面的生效目录。
- `adb/`：历史遗留目录，不被运行时引用。

新增平台二进制时放进对应平台源目录的同名子目录。非 Windows 构建若缺少平台源目录，准备脚本会直接报错，避免打包出不可用的安装包。

CI runner 每次构建都是干净环境；本机切换平台构建后，生效目录会保留上一次的平台二进制，重新构建前需再次执行准备脚本。
